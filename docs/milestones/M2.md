## Cách chạy

```text
npm install
npm start
```

Mở `http://localhost:3000/uno` để tạo phòng, hoặc dùng link/QR từ phòng UNO. Nếu chạy với `GANG_DATA_FILE`, ván UNO đang chờ/đang chơi lưu ở tệp `*.uno.json` cùng thư mục.

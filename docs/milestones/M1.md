## Thiết kế đã triển khai

### Registry và ranh giới game

`src/platform/gameRegistry.js` là nguồn server-owned cho `gameId`, `category`, tên, rules version, min/max players, config schema, status, variant metadata và capabilities. Client chỉ render catalog nhận được từ API; `category` hoặc `status` client gửi khi tạo phòng bị bỏ qua. `the-gang` là game playable duy nhất trong M1.

`src/platform/roomService.js` tách transport/platform khỏi lựa chọn game. `src/games/the-gang/adapter.js` là transitional adapter gọi engine The Gang hiện có. `GameManager` vẫn được export qua API cũ và `createGameServer().gm` vẫn giữ compatibility cho test/consumer cũ; chưa tuyên bố rằng toàn bộ room lifecycle đã được tách khỏi file luật cũ.

### Room config và migration

- Snapshot mới dùng storage version `2`; dữ liệu version `1` được đọc và ánh xạ mặc định `category=casual`, `gameId=the-gang`, `variant=standard`, đồng thời ánh xạ `mode` cũ sang `difficulty` và giữ token/history.
- Phòng lưu `config.roomName`, `maxPlayers`, `visibility` và `passwordHash`; không lưu password rõ. State gửi cho từng người chỉ có metadata cần thiết (`gameId`, category, variant, difficulty, room name, visibility, max players).
- `maxPlayers` lấy từ registry/config của game, không còn hard-code giới hạn nền tảng trong transport. Với The Gang, server kiểm tra 2–6 khi tạo/vào/bắt đầu.
- Sự kiện `create_room`, `join_room`, `resume_room`, `set_ready` cũ còn hoạt động. Sự kiện nền mới có `room:create`, `room:join`, `room:resume`, `room:ready`; adapter mới vẫn dùng state redaction/broadcast The Gang hiện có.

## File chính

- `src/platform/gameRegistry.js` — registry, catalog và validation config.
- `src/platform/roomService.js` — platform room facade, public room listing, playable guard.
- `src/games/the-gang/adapter.js` — ranh giới chuyển tiếp cho The Gang.
- `src/gameEngine.js` — version migration, password verification, room config/public view và giữ toàn bộ luật The Gang.
- `src/httpServer.js` — API registry/room listing/room metadata, deep-link fallback và event mới/cũ.
- `public/index.html`, `public/css/portal.css`, `public/js/portal.js` — home/category/detail/room entry/404 và route shell.
- `public/js/app.js`, `public/js/enhancements.js` — nối state sảnh/bàn cũ với metadata mới, không tự resume khi người dùng chỉ xem `/`.
- `test/platform.test.js` — test registry, release guard, password/capacity, privacy, migration và HTTP surface.
- `scripts/browser-check.js` — flow browser M1 qua home/detail/deep link cùng hồi quy bàn The Gang.

5. M1 không tạo profile/wallet/mission/SQLite và không chuyển chip xếp hạng The Gang sang ví. Màn hình chủ động giải thích ví/nhiệm vụ chưa mở ở M3.
6. Giữ session token legacy trong snapshot để reconnect tương thích M0; việc hash/đổi cơ chế token persistence sâu hơn để mốc persistence sau xử lý.

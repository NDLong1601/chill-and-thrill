## Lưu trữ và khôi phục

- Migration v1 → v2 chỉ thêm bảng snapshot riêng. Test nâng cấp giữ token xác thực, số dư và reservation cũ; `integrity_check` đạt.
- Snapshot Poker chứa state server để khôi phục, bao gồm thông tin ghế và bài riêng. Nó không được trả qua API metadata/hồ sơ. JSON vẫn phục vụ tương thích, nhưng không còn quyết định buy-in đã commit hay chưa.
- Dashboard đọc stack từ snapshot Poker đã commit, kể cả khi crash xảy ra trước khi metadata phòng/JSON cập nhật.
- Lỗi ghi snapshot Poker rollback cả DB và state bộ nhớ; thông báo thành công/state và `room_left` chỉ phát sau commit. Test lỗi cash-out ở ghế thứ hai xác nhận cả lần cash-out đầu cũng rollback.
- Trước sửa đã sao lưu mã nguồn vào `.migration-backups/review-fixes-20261005` (Git ignore). Không chạy server/test trên dữ liệu người chơi thật.
- Khi sao lưu để khôi phục vận hành, dừng server và sao chép toàn bộ `data`, gồm SQLite và các JSON riêng. Không chỉ phục hồi JSON Poker lên DB đang có ledger khác thời điểm.
